# Hashing & Hash Maps

A from-scratch beginner project that demystifies the single most useful data structure in interviews. You first build a working hash map by hand — a hash function, buckets, and collision handling by chaining — then build a second one with open addressing to feel the tradeoff, and finally apply the structure to the canonical hashing problems: complement lookups, frequency counting, dedup, and grouping. Throughout, the Socratic dialogue teaches the WHY: why hashing gives amortized O(1), what collisions cost, and why "amortized" is the precise word.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).
